# On plain text

Plain text is the most durable file format we have. A `.md` file written in
2004 still opens cleanly in any editor on any operating system, with no
licensing concerns and no bit rot.

## Composability

Text composes. You can:

- `grep` it
- `diff` it
- pipe it into other tools
- version it with git
- render it to HTML, PDF, EPUB, or ANSI

## Forcing clarity

Writing in plain Markdown forces you to focus on **structure** over
**decoration**. There are no fonts to choose, no colors, no layout. Just
headings, paragraphs, and the occasional list.

## Where I keep mine

This blog is the same. One file per post, in `posts/`, no CMS. Adding an
article is `vim posts/03-something.md` and reconnecting.
